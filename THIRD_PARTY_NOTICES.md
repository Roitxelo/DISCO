# Avisos de terceros

DISCO utiliza software sujeto a sus propias licencias:

- **Electron** — MIT.
- **React / React DOM** — MIT.
- **Meyda** — MIT.
- **electron-vite / Vite** — MIT.
- **electron-builder** — MIT.
- **FFmpeg**, mediante `ffmpeg-static` — el paquete declara GPL-3.0-or-later. La compilación concreta determina las obligaciones aplicables.
- **yt-dlp** — Unlicense. Se descarga desde publicaciones oficiales y se verifica.

El instalador debe conservar los avisos incorporados por Electron y dependencias. Antes de distribución comercial o pública amplia debe revisarse específicamente la compilación de FFmpeg.
