# Problemas conocidos de 0.1.0-beta.1

- Windows puede mostrar SmartScreen porque el ejecutable no está firmado.
- macOS puede bloquear inicialmente la aplicación porque el DMG no está firmado ni notarizado.
- La primera operación de YouTube descarga y verifica `yt-dlp`.
- El análisis es estimativo; mitad/doble tempo y modos paralelos pueden aparecer como alternativas.
- Los bemoles se muestran mediante sostenidos equivalentes.
- Elementos anteriores a v3.2 conservan su análisis histórico.
- La importación local referencia el original y no lo copia.
- Mover o borrar archivos fuera de DISCO requiere volver a enlazarlos.
- No hay actualizaciones automáticas.
- La beta está validada manualmente en Windows x64 y macOS Intel x64.
- macOS Apple Silicon arm64 todavía no está validado.
